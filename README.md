# The CRESCENT Transient Detection Exercise

[![License: BSD-3-Clause](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](LICENSE)

This notebook provides an overview of the dataset to be utilized in the CRESCENT Transient Detection Workshop run by the C3S Working Group (https://cascadiaquakes.org/c3s/).

We have generated several netCDF files of GNSS displacements and tremor that can be utilized in the exercise. There are three data providers: SOPAC, UNR, and PANGA. For each data provider, we have both a trended and detrended dataset, as published by those processing centers. The tremor data is from the PNSN tremor catalog, and each dataset encompasses the same time period.

Additionally, we have generated a requirements document

**Workshop:** https://cascadiaquakes.org/c3s/
